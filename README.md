Console Calculator — консольный калькулятор на C#, который умеет считать в двух режимах: обычном, инженерном.
Программа демонстрирует принципы ООП и ведёт историю всех вычислений.
Требования
ОС: Windows 7 / 8 / 10 / 11
Платформа: .NET Framework 4.7.2 или выше
Среда разработки: Visual Studio 2019 / 2022

Как запустить
Скачайте или склонируйте проект.
Откройте файл решения (.sln) в Visual Studio.
Нажмите F5 — программа скомпилируется и запустится.

Использование
Запустите программу — откроется обычный калькулятор.
Нажатие на кнопку "Инженерный калькулятор" откроет Инженерный калькулятор.

App.xaml.cs -	Основной файл с исходным кодом всех классов программы
App.config -	Файл конфигурации приложения
CalculatorProject.csproj -	Файл проекта
Properties/AssemblyInfo.cs -	Метаданные сборки
bin -	Каталог с результатами сборки
obj -	Каталог с промежуточными файлами компиляции

Классы в Program.cs
ICalculator -	Интерфейс с методами Run() и SetColor()
CalculatorBase -	Базовый класс: история, ввод чисел, цвета
BasicCalculator -	Обычные арифметические операции
EngineeringCalculator -	Синус, косинус, логарифмы и др.
DateCalculator -	Работа с датами
MainCalculator -	Главное меню и точка входа

Данные, с которыми работает программа:
История вычислений, вводимые числа, даты
